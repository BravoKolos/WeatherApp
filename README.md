## Project info:
Weather app using JavaScript, HTML and CSS. The app will fetch current weather information from an API based on the user input i.e. city name. 

## Objectives:
  - DOM manupulation
  - Creating a responsive design
  - JS functions and API calls
  - Error handling

This project uses the OpenWeather API from https://openweathermap.org/current. Before everything, an account needs to be created so that a unique API key is generated to be used in code later on. The call allows for pasting of the API token within the code: https://api.openweathermap.org/data/2.5/weather?lat={lat}&lon={lon}&appid={API key}.
